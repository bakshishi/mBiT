📂 Struktura Katalogów:
├── src/             📝 Kod źródłowy (React + TypeScript)
│   ├── App.tsx      → Routing (HashRouter) i drzewo tras
│   ├── main.tsx     → Punkt wejścia aplikacji
│   ├── components/  → Layout, Header, Footer, CookieBanner, SmartImage, ...
│   ├── pages/       → Strony serwisu (Home, Meshtastic, MeshCore, Reticulum, PMR446, CB,
│   │                  Systems, Plan, Resources, Tests, Privacy, Cookies, Accessibility, EAA)
│   │   └── cb/ plan/ pmr/ systems/  → podsekcje dużych stron
│   ├── hooks/, lib/ → Pomocnicze hooki i funkcje
│   └── shadcn.css   → Style bazowe (zmienne Tailwind/shadcn)
├── public/          🖼️ Zasoby statyczne kopiowane do dist/ (images/*.webp, favicon.svg, robots.txt)
├── scripts/         🔧 build.mjs — build i serwer deweloperski (esbuild + Tailwind)
├── .github/workflows/ ⚙️ pages.yml (wdrożenie na GitHub Pages), ci.yml (build + typecheck dla PR)
├── index.html       📄 Szablon strony (wejście dla buildu)
├── package.json     📦 Zależności i skrypty (dev, build, typecheck)
├── tsconfig.json    🧩 Konfiguracja TypeScript
├── tailwind.config.js 🎨 Konfiguracja Tailwind CSS
├── README.md        📖 Dokumentacja projektu
├── DeploymentGuide.txt 🚀 Przewodnik wdrożenia
└── dist/            (generowany przez `npm run build`, nie jest w repozytorium)

🚀 Szybki Start:
1. Zainstaluj Node.js (wersja 20 lub nowsza)
2. W katalogu głównym projektu uruchom: npm install
3. Tryb deweloperski (live reload): npm run dev — adres wyświetli się w konsoli
4. Build produkcyjny: npm run build — wynik w katalogu dist/
5. Sprawdzenie typów: npm run typecheck

💡 Wskazówki:
- Edytuj pliki wewnątrz src/ i public/, a następnie przebuduj projekt
- Katalog dist/ jest generowany — nie edytuj go ręcznie i nie dodawaj do repozytorium
- Obrazy dodawaj do public/images/ w formacie WebP i odwołuj się do nich ścieżką względną (images/nazwa.webp)
- Po pushu do gałęzi main strona jest automatycznie budowana i publikowana na GitHub Pages
- Projekt korzysta z technologii TypeScript i Tailwind CSS
